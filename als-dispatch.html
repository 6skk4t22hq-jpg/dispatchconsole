Log entry actions

Hover any entry to reveal:

⚠ FlagMark as priority (red highlight)
⚠ IncidentOpen incident form pre-filled from this message
✕Delete the entry

Click any timestamp to edit the time manually.

Incidents

Use Log Incident in the right panel or ⚠ Incident on a log entry. Severity levels:

Code 1Minor — informational
Code 2Moderate — monitor closely
Code 3Critical — immediate response

Expand a card to assign SAGs, change severity, add notes, or declare it over. Assigning a SAG sets it Occupied; declaring over auto-returns all SAGs to Available.

SAG vehicles

Click a SAG's status badge to cycle: Available → En Route → On Scene. Occupied is set automatically via incident assignment. Each SAG has a persistent notes field and a 💬 thread.

Personnel

Open ⚙ Manage stations → Personnel to add people with name, callsign, cell, assignment, and shift hours. Assign people to stations and SAGs directly from those cards — they appear as purple chips.

Map

The map is always visible in the right panel. Click ✎ Change to enter any CalTopo URL, bare map ID (e.g. 11PH4S2), or a Google Maps share URL. Use ⧉ Pop out to open in a second window. Click the event title in the top bar to rename the event.

Filters & search

Use the search box to filter by callsign, station name, or message text.

End of event report

Click End of event report then Print / Save PDF. Includes incidents, SAG traffic, station roster, personnel list, and full traffic log with notes.

Reset / Clear event wipes the log and incidents (password: accert2026). Stations, SAGs, and personnel are preserved.

Firebase live sync

When Firebase is configured the ● Live chip confirms all operators share the same log in real time. Without Firebase the app runs in local-only mode. See the comments at the top of index.html for setup.
